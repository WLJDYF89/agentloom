# scripts

运维 / 数据生成 / 故障注入脚本的存放位置。

## 排期表进度更新

```sh
python scripts/set_task_status.py A03=已完成 A04=已完成
```

- 唯一写入点是「任务明细」的 M 列（状态），「进度看板」全部由公式驱动，改完重算即可。
- 按任务 ID 定位行，不硬编码行号；先全量校验再统一写入，遇到非法状态或找不到的 ID 会整批拒绝。
- 合法状态：`未开始` / `进行中` / `已完成` / `已延期` / `已砍`（与表里下拉一致）。
- `--list` 看全部任务与当前状态，`--dry-run` 只显示改动不写盘。
- 改完用 Excel / WPS 打开会自动重算；命令行处理时可用支持重算的工具刷新公式缓存值。
- 需要 `openpyxl`（用系统 Python 即可，不必装进 `backend/.venv`）。
